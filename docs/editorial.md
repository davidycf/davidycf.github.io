# 家庭自用手册：编辑原则

面向了解本次旅行的家庭成员，不是陌生游客。家庭明确选择与 Agent 自行推导的限制不同；保留用户意图，条件、默认值、时间、数量、价格及其来源时效不能因润色而改变。

- 面向自用家庭而非陌生游客：只提供具体事实、选择和实际代价（时间、体力、行李重量、排队、费用），不替读者管理购物欲、预算或判断“多少才够”。
- 不给心理许可：不写“买不到不遗憾”“不强求”“孩子困了就取消”“不要求扫完所有店”这类安抚或允许。
- 不写泛化免责声明：不反复声明“菜单／价格／营业时间／库存以当日现场为准”；只保留具体、已知且影响本次行程的不确定性（如水巴减班、志津香每月不定休、2027 年 3 月放票或改点未公布）并说明原因。
- 不泄漏编辑指令或调研过程：正文中不出现“这次没有核实”“不把某展品写成必看”“不保存旧门牌”“这册不把某物列为返美礼物”这类写给作者/维护者的说明；缺的事实尽量补齐或记入待办。
- 不重复强调“克制哲学”：留白日、可换卡、可选支线与雨天替代已由页面功能承载，不在各站文案里反复写“一天进一个馆就够”“半天只排一个主项目”“选两块就够”。
- 保留高价值可执行提醒：安全与年龄限制、带娃实操、排队/现做耗时、退税与保修规则、本次日期相关的休息日、抽签/付款期限、季节禁捕、行李寄送时效及路线/费用差异都应完整保留。
- 保留个性与生活感：用熟悉一家人的朋友口吻，保留真实偏好与趣味（如《428》散步、爸爸钻店、酒店玩花札），不改写成冰冷的百科全书。
- 优先删除而非硬改：删去后不损失事实或决策价值的句子直接删除；界面已提示的信息（如换卡不改票）不在景点文案里重复写。

## 事实和状态
- 删除泛化免责时保留来源、核对日期、事实适用条件和证据的范围。未知不改成确定陈述；过时或缺失的重要信息先查证，必要时记入待办。计划、已订、已支付、已确认联系、已出票不是同一状态。
- 每次修改相关旅行资料时核对最新 JSON 和相关官方资料；核对日期只更新实际复核的条目，不统一假装全站已核实。
- 用户面前只写当前方案。取消或改变的安排从正文移除，理由留在决策文档或 PR；只有真会混淆才用否定。备用资料状态由界面显示。店名地名保留原文，公开页面用哥哥、妹妹、爸爸、妈妈。
- 交通、政策、季节、票务的具体不确定性和可执行提示应保留；不把官方 FAQ 当成本次预约已确认。
